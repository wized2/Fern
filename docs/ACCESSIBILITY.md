# Accessibility notes

Fern aims to stay usable with TalkBack and large fonts.

## Bottom navigation
Each destination exposes a clear content description:

| Tab | Content description |
| --- | --- |
| Home | Home dashboard |
| Details | Hardware details |
| Active apps | Active apps list |
| More | More options |

## Sharing
Share actions on Details include distinct labels for plain text, Markdown, and CSV exports so screen readers can distinguish them.

## Audits
Open issues tagged `accessibility` welcome content-description and contrast reports.
