What Fern tracks

Live gauges and trends on Home, deep stats in Details, and optional elevated access for advanced metrics.

◎ CPU & RAM

Live usage gauges, per-core detail, load averages, and memory breakdown — with trend sparklines on Home.

🌡 Thermal

Battery and system thermal status. Advanced mode can read real thermal zones via Shizuku or root.

🔋 Battery & storage

Level, temperature, health, and internal storage at a glance — designed for quick checks, not clutter.

📱 Active apps

See recently active apps. With Usage access + Advanced mode, per-app RAM (and more) stays on-device.

🏝 Dynamic Island

Optional notch-style overlay for temp and RAM — draggable, resizable, Material 3 pill design.

🔒 Private by design

No internet permission for core monitoring. No tracking. Optional Shizuku/root only when you enable Advanced mode.

Screenshots

Soft green Material 3 surfaces — light and OLED-friendly dark themes in the app.
